# Sentinel "who" model Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Name people correctly, preferring "Person" to a wrong name, using a small
whole-person ("who") model trained on home footage. Night alerts carry the names.

**Architecture:** Phase 0 measures today's wrong names and makes a quick fix. On the PC
(RTX 5070, `D:\sentinel-train\who\`), user-named sightings seed person tracks in
footage pulled from the Pi. Reviewed track crops train a MobileNetV3-small embedding,
exported to ONNX. On the Pi, `detect.py` serves it as model `"who"`, and `faces.go`
uses it with a precision-first rule: long-term gallery from user names only, same-day
"outfit" memory, event vote. `alerts.go` asks for names before sending.

**Tech Stack:** Go backend (`sentinel/backend`), Python ONNX worker
(`sentinel/detect/detect.py`), PC: Python 3.14 venv `D:\sentinel-train\venv`
(torch 2.14 cu130, torchvision 0.29, transformers 5.19, opencv 5, onnxruntime 1.30).

**Spec:** `docs/superpowers/specs/2026-10-11-who-model-design.md`

## Global Constraints

- Wrong-name rate ≤ 1% of named sightings, day and night separately. Strangers named as family ≤ 1%.
- Unsure → no name. Night alert caption says exactly `Person` (never "(not sure)").
- Only user-named sightings (`By == "you"`) enter the long-term gallery. Auto-named sightings never do.
- IR (night) tracks are never auto-accepted into training data. Every track used must come from a reviewed sheet.
- The model and training data are never published or pushed anywhere (home footage). `who.onnx` lives only in `/addon_configs/3ad1f875_sentinel/models/` (container: `/config/models/`).
- Never write or fsync while holding the faces or events locks. Heavy work runs outside `f.mu`.
- Alert "who" step budget: 3 s, then fall back to the unnamed label.
- YOLOX person detection stays. Old face models are removed only after Task 14's gate.
- Never name or junk the user's real faces in tests. Use dry/explain paths only.
- Every Sentinel change: bump `version` in `sentinel/config.yaml`, push, wait for the "Sentinel image" run (`gh run watch`), then `ha_manage_app` check_updates + update.
- Commit with `git -c user.name=SadikTD -c user.email=sadikhossain747@gmail.com commit …`. `git fetch` first. Edit scripts with Python/Edit tool, not sed.
- **Go tests** run on the Pi (no Go on the PC). From `pdc-ha-addons/`:
  `tar -C sentinel/backend -cf - . | ssh hass 'rm -rf /tmp/sb; mkdir -p /tmp/sb; tar -C /tmp/sb -xf -; command -v go >/dev/null || sudo apk add -q go; cd /tmp/sb && gofmt -l . ; go test -run "PATTERN" .'`
  (referred to below as **GOTEST PATTERN**). `gofmt -l` must print nothing (Windows writes CRLF).
- PC Python runs as `D:\sentinel-train\venv\Scripts\python.exe` (referred to as **PY**) from `D:\sentinel-train\who`.

## Review Focus

1. **Two people at once** (e.g. Mom and Dad on the stairs): each gets their own name or none, never swapped. The event vote must not cancel two different people standing apart. Test in Task 10 (`TestEventPeopleTwoApart`).
2. **A stranger who looks like family at night** must come out as `Person`. Eval reports stranger→family separately for night (Task 8), and the alert label drops Unnamed people (Task 12 `TestAlertLabel`).
3. **Detector down or `who.onnx` missing**: alerts still go out on time with the old label, sightings stay unnamed, no crash. Test in Task 12 (`TestWhoAtNoModel`); Task 9 self-check covers the wrong-size request.
4. **The outfit window across midnight** (11 pm sighting anchored at 10:30 pm) must still match. Uses time, not calendar day. Test in Task 10 (`TestDecideOutfitAcrossMidnight`).
5. **User correction wins immediately**: a sighting the user said "not Dad" never becomes Dad by body, and a user-named sighting is never cancelled by a model guess. Tests in Task 10 (`TestDecideRespectsNot`, `TestEventPeopleUserWins`).

```python
ROOT = r'D:\sentinel-train\who'
DATA = ROOT + r'\data'
REC = DATA + r'\rec'
WORK = ROOT + r'\work'
TZ = datetime.timezone(datetime.timedelta(hours=6))
CROP_W, CROP_H = 128, 256

def vec(b64):
    return np.frombuffer(base64.b64decode(b64), '<f4').copy() if b64 else None

def people():
    return {p['id']: p for p in json.load(open(DATA + r'\faces\people.json', encoding='utf-8'))}

def seen():
    out = []
    d = DATA + r'\faces\seen'
    for f in sorted(os.listdir(d)):
        out += json.load(open(os.path.join(d, f), encoding='utf-8'))
    return sorted(out, key=lambda s: s['t'])

def day(ms):
    return datetime.datetime.fromtimestamp(ms / 1000, TZ).strftime('%Y%m%d')

def closeness(v, refs):  # mean of the three most alike (faces.go closeness)
    if not refs:
        return 0.0
    s = np.sort(np.stack(refs) @ v)[::-1][:3]
    return float(s.mean())

def best_match(v, gallery, not_=()):  # faces.go bestMatch
    best, bs, second = '', 0.0, 0.0
    for p, refs in gallery.items():
        if p in not_:
            continue
        s = closeness(v, refs)
        if s > bs:
            best, bs, second = p, s, bs
        elif s > second:
            second = s
    return best, bs, second

if __name__ == '__main__':
    a = np.array([1, 0], np.float32); b = np.array([0, 1], np.float32)
    assert best_match(a, {'x': [a], 'y': [b]}) == ('x', 1.0, 0.0)
    assert best_match(a, {'x': [a], 'y': [b]}, not_=('x',))[0] == ''  # y scores 0 → no match
```

```python
import collections, numpy as np
from lib import *
P = people(); S = seen()
named = [s for s in S if s.get('by') == 'you' and s.get('person') in P and not s.get('junk')]
for s in named:
    s['_e'], s['_l'] = vec(s.get('emb')), vec(s.get('look'))
days = sorted({day(s['t']) for s in named})
fam = lambda p: p and not P.get(p, {}).get('unnamed')

def face_run(match, margin):
    res = collections.Counter()
    for d in days:
        g = collections.defaultdict(list)
        for s in named:
            if day(s['t']) != d and s['_e'] is not None:
                g[s['person']].append(s['_e'])
        for s in named:
            if day(s['t']) != d or s['_e'] is None or s.get('q', 0) < 0.3:
                continue
            p, bs, sec = best_match(s['_e'], g, s.get('not') or ())
            k = 'night' if s.get('night') else 'day'
            res[k, 'n'] += 1
            if bs >= match and bs - sec >= margin:
                res[k, 'named'] += 1
                if p != s['person'] and (fam(p) or not fam(s['person'])):
                    res[k, 'wrong'] += 1
    return res

def clothing_run(m=0.78, mg=0.08, win=6 * 3600e3):
    res = collections.Counter()
    for s in named:
        if s.get('night') or s['_l'] is None:
            continue
        best = {}
        for n in named:
            if n is s or n.get('night') or n['_l'] is None or abs(n['t'] - s['t']) > win or n['event'] == s['event']:
                continue
            best[n['person']] = max(best.get(n['person'], 0), float(np.minimum(s['_l'], n['_l']).sum()))
        res['n'] += 1
        if best:
            top = sorted(best.items(), key=lambda x: -x[1]) + [('', 0)]
            if top[0][1] >= m and top[0][1] - top[1][1] >= mg:
                res['named'] += 1
                res['wrong'] += top[0][0] != s['person']
    return res

pct = lambda a, b: 100 * a / max(b, 1)
print('user-named sightings:', len(named), 'days:', len(days))
rows = []
for match in (0.42, 0.46, 0.50, 0.54, 0.58):
    for margin in (0.07, 0.10, 0.14):
        r = face_run(match, margin)
        w = {k: pct(r[k, 'wrong'], r[k, 'named']) for k in ('day', 'night')}
        n = {k: pct(r[k, 'named'], r[k, 'n']) for k in ('day', 'night')}
        rows.append((match, margin, w, n))
        print(f'face match {match:.2f} margin {margin:.2f}: day wrong {w["day"]:4.1f}% named {n["day"]:4.1f}% | night wrong {w["night"]:4.1f}% named {n["night"]:4.1f}% (n={r["night","n"]})')
c = clothing_run()
cw = pct(c['wrong'], c['named'])
print(f'clothing (0.78/0.08, same day ±6h): wrong {cw:.1f}% named {pct(c["named"], c["n"]):.1f}% (n={c["n"]})')
ok = [r for r in rows if r[2]['day'] <= 1 and r[2]['night'] <= 1]
pick = max(ok, key=lambda r: r[3]['day']) if ok else rows[-1]
print(f'PICK faceMatch={pick[0]:.2f} faceMargin={pick[1]:.2f} clothing={"on" if cw <= 1 else "off"}')
```

```python
import cv2, bisect
CONTAINER = 'app_3ad1f875_sentinel'

def events():
    out = {}
    root = DATA + r'\events'
    for cam in os.listdir(root):
        if not os.path.isdir(os.path.join(root, cam)):
            continue
        for f in os.listdir(os.path.join(root, cam)):
            if f.endswith('.json'):
                for e in json.load(open(os.path.join(root, cam, f), encoding='utf-8')):
                    out[cam, e['id']] = e
    return out

def _starts(cam):  # recording files: YYYYmmdd-HHMMSS-*.mp4, names in UTC
    d = os.path.join(REC, cam)
    fs = sorted(f for f in os.listdir(d) if f.endswith('.mp4')) if os.path.isdir(d) else []
    ts = [datetime.datetime.strptime(f[:15], '%Y%m%d-%H%M%S').replace(tzinfo=datetime.timezone.utc).timestamp() * 1000 for f in fs]
    return fs, ts
_idx = {}

def frame(cam, ms):
    if cam not in _idx:
        _idx[cam] = _starts(cam)
    fs, ts = _idx[cam]
    i = bisect.bisect_right(ts, ms) - 1
    if i < 0 or ms - ts[i] > 62000:
        return None
    cap = cv2.VideoCapture(os.path.join(REC, cam, fs[i]))
    cap.set(cv2.CAP_PROP_POS_MSEC, ms - ts[i])
    ok, bgr = cap.read()
    cap.release()
    return bgr[:, :, ::-1].copy() if ok else None

def body_rect(b):  # same padding as faces.go body()
    x0, y0 = max(b['x'] - b['w'] * 0.05, 0), max(b['y'] - b['h'] * 0.03, 0)
    x1, y1 = min(b['x'] + b['w'] * 1.05, 1), min(b['y'] + b['h'] * 1.03, 1)
    return x0, y0, x1 - x0, y1 - y0

def crop(rgb, box):
    h, w = rgb.shape[:2]
    x, y, bw, bh = body_rect(box)
    x0, y0, x1, y1 = int(x * w), int(y * h), int((x + bw) * w), int((y + bh) * h)
    if x1 - x0 < 16 or y1 - y0 < 32:
        return None
    return cv2.resize(rgb[y0:y1, x0:x1], (CROP_W, CROP_H), interpolation=cv2.INTER_LINEAR)

def is_night(rgb):  # IR: no colour (faces.go clothes() makes the same call)
    a = rgb[::8, ::8].astype(np.int16)
    return float(np.abs(a[..., 0] - a[..., 1]).mean() + np.abs(a[..., 1] - a[..., 2]).mean()) < 6
```

```python
import os, sys, json, numpy as np
from lib import *

def iou(a, b):  # boxes [x, y, w, h] normalised
    ix = max(0, min(a[0] + a[2], b[0] + b[2]) - max(a[0], b[0]))
    iy = max(0, min(a[1] + a[3], b[1] + b[3]) - max(a[1], b[1]))
    i = ix * iy
    return i / (a[2] * a[3] + b[2] * b[3] - i + 1e-9)

def link(tracks, dets, t):
    """Extend open tracks with this frame's person boxes. A track ends after 2 missed
    frames, or when people cross (a box overlapping two tracks, or two boxes overlapping
    each other): labels must never jump from one person to another."""
    crossing = {i for i, a in enumerate(dets) for j, b in enumerate(dets) if i != j and iou(a, b) >= 0.2}
    used = set()
    for tr in tracks:
        if tr['closed']:
            continue
        last = tr['boxes'][-1][1]
        m = [i for i, d in enumerate(dets) if iou(last, d) >= 0.3]
        if len(m) == 1 and m[0] not in crossing and m[0] not in used:
            tr['boxes'].append((t, dets[m[0]])); tr['miss'] = 0; used.add(m[0])
        elif m:
            tr['closed'] = True  # ambiguous: two candidates, a crossing, or taken
            used.update(m)
        else:
            tr['miss'] += 1
            tr['closed'] = tr['miss'] > 2
    for i, d in enumerate(dets):
        if i not in used and i not in crossing:
            tracks.append({'boxes': [(t, d)], 'miss': 0, 'closed': False, 'names': set()})

if __name__ == '__main__' and sys.argv[1:] == ['test']:
    T = []
    link(T, [[.1, .1, .1, .3]], 0); link(T, [[.11, .1, .1, .3]], 250)
    assert len(T) == 1 and len(T[0]['boxes']) == 2
    link(T, [[.11, .1, .1, .3], [.13, .1, .1, .3]], 500)  # someone walks into them
    assert T[0]['closed'] and len(T) == 1  # neither box starts a track while crossing
    T = []; link(T, [[.1, .1, .1, .3]], 0); link(T, [], 250); link(T, [], 500); link(T, [], 750)
    assert T[0]['closed']
    print('tracks ok'); sys.exit()
```

```python
import torch
from PIL import Image
from transformers import AutoImageProcessor, DFineForObjectDetection
dp = AutoImageProcessor.from_pretrained('ustc-community/dfine-xlarge-obj2coco')
dm = DFineForObjectDetection.from_pretrained('ustc-community/dfine-xlarge-obj2coco').to('cuda').eval()

@torch.no_grad()
def people_in(rgb):
    im = Image.fromarray(rgb)
    o = dm(**dp(images=im, return_tensors='pt').to('cuda'))
    r = dp.post_process_object_detection(o, threshold=0.5, target_sizes=[im.size[::-1]])[0]
    W, H = im.size
    return [[b[0] / W, b[1] / H, (b[2] - b[0]) / W, (b[3] - b[1]) / H] for s, l, b in
            zip(r['scores'], r['labels'], r['boxes'].tolist()) if dm.config.id2label[l.item()] == 'person']

P = people(); E = events()
seeds = {}
for s in seen():
    if s.get('by') == 'you' and s.get('person') in P:
        seeds.setdefault((s['cam'], s['event']), []).append(s)
os.makedirs(WORK + r'\crops', exist_ok=True)
done = set()
out_path = WORK + r'\tracks.jsonl'
if os.path.exists(out_path):
    done = {tuple(json.loads(l)['id'].split('|')[:2]) for l in open(out_path)}
out = open(out_path, 'a')
for (cam, ev), ss in sorted(seeds.items()):
    e = E.get((cam, ev))
    if not e or (cam, ev) in done:
        continue
    t, end = e['start'] - 1000, min(e['end'] or e['start'] + 60000, e['start'] + 60000) + 1000
    T, rgbs = [], {}
    while t <= end:
        rgb = frame(cam, t)
        if rgb is not None:
            rgbs[t] = rgb
            link(T, people_in(rgb), t)
```

```python
import torch, torch.nn as nn, torchvision
MEAN = torch.tensor([0.485, 0.456, 0.406]).view(1, 3, 1, 1) * 255
STD = torch.tensor([0.229, 0.224, 0.225]).view(1, 3, 1, 1) * 255

class Net(nn.Module):
    def __init__(self, n_ids, pretrained=True):
        super().__init__()
        b = torchvision.models.mobilenet_v3_small(weights='IMAGENET1K_V1' if pretrained else None)
        self.features = b.features  # 576 channels
        self.emb = nn.Linear(576, 256)
        self.bn = nn.BatchNorm1d(256)
        self.cls = nn.Linear(256, n_ids, bias=False)
        self.register_buffer('mean', MEAN); self.register_buffer('std', STD)

    def embed(self, x):
        x = (x - self.mean) / self.std
        return self.bn(self.emb(self.features(x).mean((2, 3))))

    def forward(self, x):
        e = self.embed(x)
        return e, self.cls(e)

if __name__ == '__main__':
    n = Net(5, pretrained=False).eval()
    e, l = n(torch.rand(2, 3, 256, 128) * 255)
    assert e.shape == (2, 256) and l.shape == (2, 5)
    print('model ok')
```

```python
from PIL import Image
from lib import WORK
from model import Net
torch.manual_seed(0); random.seed(0)
D = json.load(open(WORK + r'\dataset.json'))

by = {}
for k, i in enumerate(tr):
    by.setdefault(i['pid'], []).append(k)
pids = [p for p, ks in by.items() if len(ks) >= 4]

net = Net(len(D['ids'])).to(dev)
opt = torch.optim.AdamW(net.parameters(), lr=3.5e-4, weight_decay=5e-4)
EPOCHS, STEPS = 60, 200
sched = torch.optim.lr_scheduler.OneCycleLR(opt, 3.5e-4, total_steps=EPOCHS * STEPS, pct_start=0.1)

def augment(x, night):
    x = x.float()
    flip = torch.rand(len(x), device=dev) < 0.5
    x[flip] = x[flip].flip(3)
    x = x * (0.6 + 0.8 * torch.rand(len(x), 1, 1, 1, device=dev)) + 40 * (torch.rand(len(x), 1, 1, 1, device=dev) - 0.5)
    grey = (torch.rand(len(x), device=dev) < 0.3) | night  # learn colourless (IR) looks
    g = x[grey].mean(1, keepdim=True).expand(-1, 3, -1, -1)
    x[grey] = g
    for k in range(len(x)):  # random erasing (occlusion by railings, doors)
        if random.random() < 0.5:
            h, w = random.randint(32, 96), random.randint(16, 48)
            y0, x0 = random.randint(0, 256 - h), random.randint(0, 128 - w)
            x[k, :, y0:y0 + h, x0:x0 + w] = 114
    return x.clamp(0, 255)

def hard_triplet(e, y, margin=0.3):
    e = F.normalize(e)
    d = torch.cdist(e, e)
    same = y[:, None] == y[None]
    pos = (d * same).max(1).values
    neg = (d + 1e3 * same).min(1).values
    return F.relu(pos - neg + margin).mean()

for ep in range(1, EPOCHS + 1):
    net.train(); tot = 0
    for _ in range(STEPS):
        ks = [k for p in random.sample(pids, min(8, len(pids))) for k in random.sample(by[p], 4)]
        x = augment(X[ks].to(dev), NIGHT[ks].to(dev)); y = Y[ks].to(dev)
        e, logits = net(x)
        loss = F.cross_entropy(logits, y, label_smoothing=0.1) + hard_triplet(e, y)
        opt.zero_grad(); loss.backward(); opt.step(); sched.step(); tot += loss.item()
    print(f'epoch {ep} loss {tot / STEPS:.3f}', flush=True)
    if ep % 10 == 0:
        torch.save({'state': net.state_dict(), 'ids': D['ids']}, WORK + rf'\who_ep{ep}.pt')
```

```python
OUTFIT_MS = 12 * 3600 * 1000

def decide(v, t, night, long, today, sure, outfit, margin):  # == Go decideWho
    p, s, sec = best_match(v, long)
    if p and s >= sure and s - sec >= margin:
        return p, 'sure'
    g = collections.defaultdict(list)
    for r in today:
        if r['night'] == night and abs(r['t'] - t) <= OUTFIT_MS:
            g[r['person']].append(r['v'])
    p, s, sec = best_match(v, g)
    if p and s >= outfit and s - sec >= margin:
        return p, 'outfit'
    return '', ''

@torch.no_grad()
def embed(net, paths):
    out = []
    for k in range(0, len(paths), 256):
        x = torch.from_numpy(np.stack([np.asarray(Image.open(p)) for p in paths[k:k + 256]])).permute(0, 3, 1, 2).float().cuda()
        out.append(torch.nn.functional.normalize(net.embed(x)).cpu().numpy())

        if len(long[i['person']]) < 300:

    first = [decide(s['v'], s['t'], s['night'], long, [], sure, outfit, margin) for s in sights]
    res = collections.Counter()
    for s, (p0, by0) in zip(sights, first):
        today = [a for a in anchors if a['track'] != s['track']] + \
                [dict(o, person=p) for o, (p, b) in zip(sights, first) if b == 'sure' and o['track'] != s['track']]
        p, _ = decide(s['v'], s['t'], s['night'], long, today, sure, outfit, margin)
        k = 'night' if s['night'] else 'day'

        if p:

            if p != s['person']:
```

```python
class Who:
    """Who-model (trained on this home's own footage, /config/models/who.onnx): a person
    crop, 128x256 RGB, to a 256-number fingerprint of unit length."""
    size = 256

    def __init__(self, path):
        self.sess = session(path)
        self.inp = self.sess.get_inputs()[0].name

    def detect(self, data, w, h):
        if (w, h) != (128, 256):
            return []
        x = np.frombuffer(data, np.uint8).reshape(h, w, 3).astype(np.float32).transpose(2, 0, 1)[None]
        v = self.sess.run(None, {self.inp: x})[0][0]
        v = v / (np.linalg.norm(v) + 1e-9)
        return [[round(float(a), 5) for a in v]]
```

```go
// Who model: a small network trained on this home's own footage (D:\sentinel-train\who)
// turns a whole person (head, build, clothes) into a fingerprint, so people are known
// from above, from behind and in infrared too, where faces aren't seen.
//
// Clothes change every day, so the fingerprint names someone only:
//   - surely, when it is very like the pictures the user named (any day), or
//   - by outfit, when it clearly matches someone already known today (named by the user,
//     by face, or surely) within outfitWindow, in the same light (colour or infrared).
// Otherwise nobody: a wrong name is worse than none. Thresholds come from eval.py
// (work/who_thresholds.json), measured at ≤1% wrong on days the model never saw.
const (
	whoSure      = 0.80 // from who_thresholds.json "sure"
	whoOutfit    = 0.70 // "outfit"
	whoMargin    = 0.08 // "margin": clearly more alike than anyone else
	whoGroup     = 0.70 // unknown people this alike are shown together (= whoOutfit)
	outfitWindow = 12 * time.Hour
	whoDim       = 256
	whoW, whoH   = 128, 256 // the crop the model takes
)

// bodyRef is one example of what someone looked like.
type bodyRef struct {
	person string
	t      int64
	night  bool
	v      []float32
}

// decideWho: who a person's fingerprint v (seen at t) is, and how ("sure"/"outfit").
// today must be sorted by t.
func decideWho(v []float32, t int64, night bool, not []string, long, today []bodyRef) (string, string, float64) {
	if p, s, second := bestRef(v, long, not); p != "" && s >= whoSure && s-second >= whoMargin {
		return p, "sure", s
	}
	w := outfitWindow.Milliseconds()
	i := sort.Search(len(today), func(i int) bool { return today[i].t >= t-w })
	j := sort.Search(len(today), func(i int) bool { return today[i].t > t+w })
	var near []bodyRef
	for _, r := range today[i:j] {
		if r.night == night {
			near = append(near, r)
		}
	}
	if p, s, second := bestRef(v, near, not); p != "" && s >= whoOutfit && s-second >= whoMargin {
		return p, "outfit", s
	}
	return "", "", 0
}

func bestRef(v []float32, refs []bodyRef, not []string) (string, float64, float64) {
	g := map[string][][]float32{}
	for _, r := range refs {
		g[r.person] = append(g[r.person], r.v)
	}
	return bestMatch(v, g, not)
}

// eventPeople: who was in an event. Sightings that are clearly one person (same place

// which always wins.
func eventPeople(ss []*Seen) []string {

	for i, a := range ss {
		for _, b := range ss[i+1:] {
			if a.Person == "" || b.Person == "" || a.Person == b.Person || abs64(a.T-b.T) > 2000 || iou(a.Box, b.Box) < 0.3 {
				continue
			}

			case a.By == "you" && b.By != "you":
				bad[b] = true
			case b.By == "you" && a.By != "you":
				bad[a] = true
			default:
				bad[a], bad[b] = true, true
			}
		}
	}
	var out []string
	for _, s := range ss {
		if s.Person != "" && !bad[s] && !slices.Contains(out, s.Person) {
			out = append(out, s.Person)
		}
	}
	return out
```

```go
	for _, d := range dets {
		if d.Label != "person" || d.Score < 0.45 || d.Box.W*d.Box.H < minBoxArea || len(ss) == 4 {
			continue
		}
		s := &Seen{Cam: cam, T: t.UnixMilli(), Box: d.Box, Night: night(full, d.Box)}
		if face, q, emb, _ := f.face(ctx, full, d.Box, func(string, ...any) {}); emb != nil {
			s.Face, s.Q, s.emb = &face, q, emb
		}
		s.body, _ = f.body(ctx, full, d.Box)
		ss = append(ss, s)
	}
	if ctx.Err() != nil {
		return nil
	}
	f.mu.RLock()
	g, junk := f.galleriesLocked()
	long, today := f.bodyRefsLocked()
	for _, s := range ss {
		s.Person, s.By, s.Sim = f.decideLocked(s, g, junk, long, today)
	}
	var names []string
	for _, p := range eventPeople(ss) {
		if i := slices.IndexFunc(f.people, func(x Person) bool { return x.ID == p }); i >= 0 && !f.people[i].Unnamed {
			names = append(names, f.people[i].Name)
		}
	}
	f.mu.RUnlock()
	return names
}
```
